## 🎯 About the Series

The **Certification Study Series** is the free certification-learning branch of the **Cyber Master Series**, an independent knowledge initiative created by **Taher Amine ELHOUARI**.

Its purpose is simple: transform official exam objectives, authoritative references, and real cybersecurity practice into **clear, structured, professional study material available without a paywall**.

> [!NOTE]
> Every released guide is tied to a specific exam outline or certification version. When an exam changes, the guide is reviewed, versioned, and updated rather than silently presented as current.

## 🚀 How the Project Is Published

The canonical home of the series is **[TaherAmine.org](https://www.taheramine.org/)**.

| Format / Channel | Purpose |
|---|---|
| **🌐 Interactive Web Edition** | Focused online study experience on TaherAmine.org |
| **📄 PDF Edition** | Downloadable edition for offline study and printing |
| **📝 DOCX Master** | Private controlled authoring source used to produce the PDF |
| **🐙 GitHub Repository** | Public project hub for releases, documentation, corrections, contributions, versioning and roadmap visibility |

> [!IMPORTANT]
> Internal HTML source and editable DOCX masters are **not** published in this repository.

<details>
<summary><strong>Why the controlled publishing model matters</strong></summary>

<br>

The project separates the private authoring source from public release formats so that editions can be reviewed, versioned and maintained consistently. GitHub acts as the public release and community layer, while TaherAmine.org remains the canonical home for the interactive study experience.

</details>
