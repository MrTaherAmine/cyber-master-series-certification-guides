## About the Series

The **Certification Study Series** is the free certification-learning branch of the **Cyber Master Series**, an independent knowledge initiative created by **Taher Amine ELHOUARI**.

The goal is simple: turn official exam objectives, authoritative references, and real cybersecurity practice into clear, structured, professional study material that learners can use without a paywall.

Each released guide is maintained as an edition tied to a specific exam outline or certification version. When an exam changes, the guide is reviewed, versioned, and updated rather than silently presented as current.

### What makes these guides different

- **Free community editions** — created to make serious certification preparation more accessible.
- **Outline-driven** — coverage is mapped to the relevant official certification or exam outline.
- **Practical, not just theoretical** — concepts are explained with governance, audit, operations, risk, architecture, resilience, and real-world security context where appropriate.
- **Version-aware** — every release identifies the exam/version it targets and the date it was last reviewed.
- **Professionally designed** — interactive web editions are built for focused study; downloadable PDFs are produced from controlled DOCX masters.
- **Independent** — these guides are not sponsored by, affiliated with, or endorsed by the certification bodies whose marks are referenced.

## How the Project Is Published

The canonical home of the series is **[TaherAmine.org](https://www.taheramine.org/)**.

For each completed guide:

1. **Interactive Web Edition** — published on TaherAmine.org and visually aligned with the website experience.
2. **PDF Edition** — downloadable from TaherAmine.org for offline study and printing.
3. **DOCX Master** — maintained privately as the controlled authoring source used to produce the PDF.

This GitHub repository is the **public project hub** for documentation, release information, corrections, contribution guidance, and roadmap visibility. Internal HTML source and editable DOCX masters are not published here.

## Contributing

Community corrections and improvement suggestions are welcome.

Good contributions include:

- factual corrections supported by a public, authoritative source;
- notifications that a certification body has changed an exam outline or objective;
- clarity improvements and typo reports;
- accessibility or usability issues affecting the public study experience;
- suggestions for future guides.

Please read **[CONTRIBUTING.md](CONTRIBUTING.md)** before opening an issue.

> **Do not submit exam dumps, recalled live-exam questions, NDA-protected material, leaked content, or copyrighted study-book content.** This project is built from legitimate public/authorized sources and original explanation.
